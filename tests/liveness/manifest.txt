# cabac_overread: 24 single-MB I_PCM pictures (synthetic CABAC, gen_cabac_overread.py).
# Each slice decodes its whole picture, but raw 0xFF bytes after the PCM samples leave the
# re-initialised cabac engine with offset >= range (end_of_slice = 1) AND a non-zero
# msb_cache - the look-ahead state a dense final slice leaves when its data fills the NAL.
# The strict cabac end check then tripped EBADMSG on these COMPLETE slices, so their
# remaining_mbs was never zeroed and the pictures never finalized. They pile up undelivered
# until the DPB overflows and the decoder spins ENOBUFS mid-stream (before end-of-stream, so
# the EOS forward-progress valve cannot mask it). A correct decoder ignores the look-ahead
# slop on a slice that decoded every macroblock and emits all 24. ffmpeg decodes them too.
# Regression (cabac end-of-slice over-read tolerance) => mid-stream stall.
cabac_overread 24
# cabac_orphan: an IDR then 23 single-MB-per-picture frames (synthetic CABAC,

# 23 of 24 and stalled. The fix finalizes and re-queues the orphan so all 24 come

# mvc_orphan_dep_tail: a two-view body (1 stereo IDR + 3 stereo P AUs, 16x16 MBs)
# followed by 32 dependent-view-only tail AUs (no base view) - the shape a
# byte-trimmed 3D-BD SSIF leaves behind (its chunked interleaving ends with a
# surplus of dependent AUs past the last base AU; an unequal-length two-file
# base+dependent feed produces the same). Generated by tests/gen_mvc_orphan_tail.py.
# Under multithreading, get_frame's orphan-dependent valve used to drop such a
# dependent while its decode tasks were still running (or while it was still being
# parsed); the parser then reallocated the freed DPB slot and the stale tasks'
# remaining_mbs subtractions corrupted the new occupant's counter - the frame never
# finalized, dependent tasks piled up, and once all 16 task slots filled the parser
# deadlocked inside edge264_decode_NAL (0% CPU; ~97% repro rate on this fixture
# pre-fix, occasionally a crash instead). The fix defers the drop until the
# dependent has no in-flight tasks and additionally bars the slot allocator from
# handing out any slot still written by a busy task. Expected: the 4 body stereo
# pairs; every tail dependent is dropped (no base to pair with), like ffmpeg.
# Regression (orphan-drop guard or allocator in-flight guard) => deadlock/crash (MT).
mvc_orphan_dep_tail 4
